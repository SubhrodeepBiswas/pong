# 🏓 Pong Game (Python Turtle Edition)

A classic Pong game built using Python’s Turtle graphics module.  
This project includes smooth gameplay, a menu system, score tracking, and a win screen.

---

## 🎮 Features

- 🟢 Start Menu Screen
- 🏆 First to 10 Wins System
- 🔄 Reset Game Button (Press R)
- 🎯 Animated Scoreboard
- ⚡ Smooth ball movement
- 🎮 Two-player controls

## 🕹️ Controls

### Left Player
- W → Move Up
- S → Move Down

### Right Player
- ↑ → Move Up
- ↓ → Move Down

### Game Controls
- SPACE → Start Game
- R → Reset Game
